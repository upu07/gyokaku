# 大野水産 漁獲帳

素潜り手銛漁の漁獲高を記録・計算するiPhone向けWebアプリ（PWA）です。Safariで開いて「ホーム画面に追加」するとアプリとして使えます。

- ① 漁獲高計算: 1回の漁を日時・場所つきで記録し、手数料・振込手数料を引いた手取りを出す
- ② 売上予測: 日数と1日2回の水揚げから売上を予測する
- ③ 過去の漁獲高: カレンダーと地図で過去の漁を振り返る。フレンドの記録も見られる

魚種は島名・和名のどちらでも検索でき、重さと匹数の計算を切り替えられます（切り替えても入力は残ります）。

## 相場データ

`data/market.json` は JF沖縄魚市場（糸満、[おきなわ魚市場情報](https://www.okinawa-fish.jp/shikyou/gyosyu/?ichiba=119)）の全魚種日別データです。GitHub Actions（`.github/workflows/market.yml`）が月〜土の13:30と18:30（日本時間）に `scripts/update_market.py` を実行して更新します。

- 予想単価 = 魚種ごとの直近7日間の「金額の合計 ÷ 水揚量の合計」（円/kg）
- 一度出た魚種は消さない。7日以内に取引がない魚種は、最後に取引があった週の値を使う
- 和名と1匹の重さの目安は `scripts/species_names.py` で管理

## アカウント（Firebase）

`config.js` の `FIREBASE_CONFIG` が `null` の間は、ログインなしでこの端末だけに保存します。

アカウントは大野水産が発行します（メールアドレス不要）。発行するときは、Firebase コンソール → Authentication → ユーザー → 「ユーザーを追加」で、次のように入れます。

- メール: `発行するID@gyokaku.ohno-suisan.app`（例: `tanaka@gyokaku.ohno-suisan.app`。実在しないアドレスで問題ありません）
- パスワード: 6文字以上

アプリでは「ID（@より前）」と「パスワード」でログインします。データを守るルールは `firestore.rules` です。
